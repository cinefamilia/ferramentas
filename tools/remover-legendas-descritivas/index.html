Remover Legendas Descritivas

Remove blocos e trechos como [risos], (música tocando), - [balbucia] etc. de um arquivo .srt

1. Regras aplicadas

• Bloco cujo texto inteiro é descritivo (ex: [risos], - [balbucia]) → o bloco é removido por completo.
• Fala misturada com descrição (ex: Oi, tudo bem? [risos]) → mantém a fala, remove só o trecho entre colchetes/parênteses (e o hífen, se estiver colado direto no colchete/parêntese).
• Hífen de virada de diálogo (- Fala do personagem) não é tocado — só é removido quando está imediatamente antes de um colchete/parêntese.
• Ao final, os blocos restantes são renumerados sequencialmente.
